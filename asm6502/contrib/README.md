# contrib/

Author: Sherman White Jr., email: subscribeandnotifyme@gmail.com c. 2026

Space for contributions from users of asm6502: example programs, macro libraries and
`.include` files, target definitions, editor syntax files, helper scripts, and so on.

Guidelines

- One subdirectory per contribution (`contrib/<name>/`), with its own short `README.md`
  saying what it is, how to use it, and who wrote it.
- Say which targets it was tried on (`c64`, `appleii`, `atari800`, `prodos`) and which
  assembler version.
- Keep it self-contained: nothing in `src/` should depend on `contrib/`.
- Don't add binaries, disk images or ROMs. Source only.
- State the license of your contribution if it differs from the repository's.
