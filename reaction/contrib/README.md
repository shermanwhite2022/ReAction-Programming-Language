# contrib/

Author: Sherman White Jr., email: subscribeandnotifyme@gmail.com c. 2026

Space for contributions from users of ReAction!: example programs, libraries (new `.ACT`
include files, other platforms), `rc` helper scripts, editor syntax files, and so on.

Guidelines

- One subdirectory per contribution (`contrib/<name>/`), with its own short `README.md`
  saying what it is, how to use it, and who wrote it.
- Say which target(s) it was tried on (Atari 800, C64, Apple II) and which `rc` version.
  If it uses hardware that differs between platforms, mark what is OS specific.
- Keep it self-contained: nothing in `src/` or `includes/` should depend on `contrib/`.
  A contribution that proves generally useful can be proposed for `includes/` or `examples/`.
- Don't add binaries (`.xex`, disk images) or ROMs. Source only.
- State the license of your contribution if it differs from the repository's.
